# Glossary

One name per concept, used the same way in the schema, the code and the UI.

| Code / schema                   | UI (Hungarian)                   | Meaning                                                                                                                                                                                           |
| ------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bill`                          | számla                           | A payable document from a supplier (MVM, Telekom, ...) with an amount due and a due date. Only bills with something to pay exist here.                                                            |
| `inbound_item`                  | beérkezett tétel                 | One thing taken from the mailbox for extraction: a PDF attachment, or the message body when the mail has no PDF. The durable queue row the extraction works from.                                 |
| `supplier`                      | szolgáltató                      | Who issued the bill. `sender_domain` is the mail domain it arrived from; it namespaces invoice numbers.                                                                                           |
| `invoice_number`                | számlaszám                       | The supplier's own number for the bill. With `sender_domain`, the bill's identity.                                                                                                                |
| `payer_id`                      | fizető azonosító                 | The customer / payer / place-of-use identifier the supplier asks to quote in the payment reference.                                                                                               |
| `amount_minor`                  | összeg                           | Integer in the currency's minor unit (fillér, cent). Never a float.                                                                                                                               |
| `due_date`                      | fizetési határidő                | A calendar date, `YYYY-MM-DD`, in Europe/Budapest.                                                                                                                                                |
| `transaction`                   | banki tétel                      | One booked debit or credit on a connected bank account, mirrored from the bank. Never edited or deleted here. (`trx` / `Transaction<Database>` in code is a database transaction, Kysely's word.) |
| `match`                         | párosítás                        | The link saying "this transaction paid this bill". One transaction pays at most one bill, one bill has at most one active match. `auto` or `manual`. Revoking keeps the row.                      |
| `paid` / `awaiting` / `overdue` | Fizetve / Fizetésre vár / Lejárt | The bill's displayed state, **derived**: an active match → paid; otherwise due date before today → overdue; otherwise awaiting. Not stored.                                                       |
| `bank session`                  | bankkapcsolat                    | An Enable Banking consent for one bank, valid until `valid_until` (~180 days).                                                                                                                    |
| `run`                           | futás                            | One execution of the mail or bank poll, with its outcome; what the status bar reads.                                                                                                              |
| `dead_lettered`                 | kézi beavatkozás kell            | An inbound item the extraction gave up on; listed in the UI, never silently dropped.                                                                                                              |
